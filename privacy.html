BioBridge Privacy Policy

Last updated: May 2026

BioBridge is an educational browser extension prototype developed for academic and research purposes. The project explores biometric-inspired authentication workflows, usability, transparency, and secure login concepts.

Information Collection

BioBridge does not intentionally collect, sell, or transfer personal user data to third parties.

Any authentication-related functionality demonstrated in the prototype is intended solely for local testing and educational purposes.

Local Storage

The extension may temporarily store local settings or authentication workflow information using browser storage APIs in order to demonstrate extension functionality.

Permissions

BioBridge uses browser permissions such as activeTab, scripting, storage, and tabs to demonstrate login detection and authentication workflows within the prototype environment.

Third-Party Services

The BioBridge prototype does not intentionally execute remote code or integrate external advertising or tracking services.

Educational Disclaimer

BioBridge is not currently a production-ready security solution and should not be relied upon for real-world authentication protection.

Contact

For questions regarding this project, please contact the project developers through the associated GitHub repository or project website.
